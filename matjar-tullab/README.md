# متجر الطلاب — سوق مقايضة لطلاب الجامعات

تطبيق ويب خفيف بـ Node.js + Express لعرض ومقايضة الكتب والأغراض الجامعية،
مع تخزين دائم للإعلانات والصور في ملفات محلية (بدون قواعد بيانات معقدة، وبدون أي مكتبات مدفوعة).

## هيكل المشروع
```
matjar-tullab/
├── server.js          # السيرفر الرئيسي (Express)
├── package.json        # الاعتماديات
├── public/              # الواجهة الأمامية
│   ├── index.html
│   ├── style.css
│   └── script.js
├── uploads/             # صور الأغراض المرفوعة (تُنشأ تلقائياً)
└── data/
    └── items.json       # قاعدة بيانات الإعلانات (تُنشأ تلقائياً)
```

## خطوات التشغيل داخل Termux

### 1. تثبيت Node.js (مرة واحدة فقط)
```bash
pkg update -y && pkg upgrade -y
pkg install nodejs -y
```
تأكد من التثبيت:
```bash
node -v
npm -v
```

### 2. فك ضغط المشروع ثم الدخول إلى مجلده
إذا استلمت المشروع كملف مضغوط (zip)، انقله إلى مجلد Termux ثم فك ضغطه:
```bash
# مثال إن كان الملف داخل مجلد Downloads بالهاتف
cp /storage/emulated/0/Download/matjar-tullab.zip ~/
cd ~
pkg install unzip -y
unzip matjar-tullab.zip
cd matjar-tullab
```

### 3. تثبيت المكتبات المطلوبة
```bash
npm install
```
سيقوم هذا بتثبيت `express` و `multer` فقط (لا حاجة لأي أدوات بناء/compiler، تعمل مباشرة على Termux).

### 4. تشغيل السيرفر
```bash
npm start
```
سترى رسالة:
```
✅ السيرفر يعمل الآن على: http://localhost:3000
```

### 5. فتح التطبيق
افتح متصفح الهاتف (Chrome مثلاً) واذهب إلى:
```
http://localhost:3000
```

> لإبقاء السيرفر يعمل في الخلفية أثناء استخدام تطبيقات أخرى، يمكنك استخدام:
> ```bash
> pkg install tmux -y
> tmux new -s server
> npm start
> ```
> ثم اضغط `Ctrl+B` ثم `D` للخروج من الجلسة دون إيقاف السيرفر. للعودة إليها لاحقاً: `tmux attach -t server`.

## التحديث الرابع — حماية وتصنيف جديد
1. **تصنيف "حسابات ألعاب"** (ببجي، فيفا، فري فاير، فورتنايت، PES...) — مع تنبيه أمان يظهر بالفورم لما يُختار هذا التصنيف، يحذر من مشاركة بيانات الاسترجاع قبل التأكد من الطرف الآخر.
2. **ضغط الصور تلقائياً بالمتصفح** قبل الرفع (تصغير للعرض الأقصى 1280px وجودة JPEG ~72%) لتوفير مساحة التخزين، خصوصاً مهم عند الاستضافة على خطة مجانية محدودة المساحة.
3. **حد أقصى للنشر اليومي**: 5 إعلانات كحد أقصى لكل جهاز خلال 24 ساعة (قابل للتعديل من `DAILY_POST_LIMIT` في `server.js`)، للحماية من السبام. ملاحظة: العداد بالذاكرة فقط، فبيتصفر تلقائياً كل مرة يعاد فيها تشغيل السيرفر.
4. **صفحة 404 مخصصة** بدل رسالة الخطأ الجامدة الافتراضية.
5. **Favicon** بسيط (إيموجي 🎓) بدون الحاجة لملف صورة خارجي.

## التحديث الخامس — الموقع الجغرافي وإصلاحات واجهة
1. **حقل المحافظة والمنطقة (قائمة تسلسلية)**: إجباري بكل إعلان جديد — اختيار المحافظة (12 محافظة أردنية) يفعّل قائمة المناطق التابعة لها تلقائياً (مثال: عمان → السابع، طبربور، الجبيهة... / جرش → ساكب، كتة، ريمون...). قابلة للتعديل من `JORDAN_LOCATIONS` بـ `server.js`.
2. **فلتر المحافظة** بشريط الفلاتر بالصفحة الرئيسية، بجانب فلتر الجامعة والتصنيف.
3. **إصلاح تراكب أزرار البطاقة**: زر "نسخ الرابط" صار نص واضح "📋 نسخ" بدل أيقونة صغيرة قد تُقرأ خطأً كغير موجودة، وصف الأزرار صار يلتف (wrap) بدل ما ينضغط أو يختفي بالشاشات الضيقة.
4. **إخفاء الوصف من بطاقة الشبكة الرئيسية**: الوصف الكامل يظهر فقط عند فتح صفحة تفاصيل الغرض، والبطاقة بالشبكة تكتفي بالاسم والشارات و"بدل بـ" — تصميم أنظف وأخف.

## التحديث الرابع — حسابات الألعاب وتحسينات تقنية
1. **تصنيف "حسابات ألعاب"** جديد، مع حقل فرعي "نوع اللعبة" (ببجي موبايل، فري فاير، فورتنايت، فيفا، بيس، كلاش أوف كلانس، ماين كرافت، روبلوكس، لعبة أخرى) يظهر شرطياً مثل حقل الجامعة تماماً.
2. **تحذير أمان تلقائي** يظهر بالنموذج عند اختيار تصنيف حسابات الألعاب، يذكّر المستخدم بعدم مشاركة بيانات استرجاع الحساب قبل التأكد من الطرف الآخر (حماية بسيطة من عمليات النصب الشائعة بتبادل الحسابات).
3. **ضغط الصور تلقائياً قبل الرفع** (بجودة ~72% وعرض أقصى 1280px) — يقلل استهلاك مساحة التخزين بشكل كبير دون التأثير الملحوظ على الجودة.
4. **حد أقصى 5 إعلانات يومياً لكل جهاز** — حماية بسيطة من السبام دون الحاجة لحسابات أو تسجيل دخول.
5. **صفحة 404 مخصصة وودّية** بدل رسالة الخطأ الافتراضية.
6. **أيقونة (Favicon)** 🎓 بعلامة تبويب المتصفح.

## التحديث الثالث — تحسينات وتسويق
1. **حركات وهوية بصرية**: اللوغو يهتز بلطف عند الـ hover، البطاقات تدخل بحركة تدريجية متتابعة عند التحميل، الأزرار تستجيب بحركة ضغط خفيفة، شارة "تمت المقايضة" تظهر بحركة pop-in، تبديل الوضع الليلي/الفاتح يصير بانتقال لوني ناعم، وسكيلتون تحميل (Shimmer) يظهر أثناء جلب البيانات بدل شاشة فاضية.
2. **زر تواصل واتساب مع صاحب المنصة**: بالفوتر — **يجب تعديل الرقم الحقيقي** في `server.js` بالثابت `DEVELOPER_WHATSAPP` (حالياً رقم تجريبي `962700000000`).
3. **زر نسخ الرابط** 📋 بجانب زر المشاركة على كل بطاقة وصفحة التفاصيل.
4. **عداد "إجمالي الإعلانات المنشورة"** يظهر أسفل قسم الترحيب بالصفحة الرئيسية.
5. **معاينة صحيحة عند المشاركة (Open Graph)**: لما تشارك رابط `/item/xxx` بواتساب أو فيسبوك، بيطلع معاينة فيها صورة الغرض واسمه تلقائياً.
6. **نظام بلاغات بسيط**: زر "🚩 إبلاغ عن هذا الإعلان" على كل إعلان (غير ظاهر لصاحب الإعلان نفسه)، يُخزَّن البلاغ بملف `data/reports.json` لمراجعته يدوياً.
7. **صفحة جامعة مخصصة**: رابط `/university/اسم-الجامعة` (مثال: `/university/الجامعة الأردنية`) يعرض الإعلانات مفلترة تلقائياً — مفيد جداً للمشاركة بمجموعات جامعة معينة.
8. **نافذة ترحيب لأول زيارة فقط**: تشرح فكرة المنصة، تظهر مرة واحدة بكل جهاز (تُحفظ بـ localStorage).

> **ملاحظتان مهمتان بخصوص مقترحات لم تُنفَّذ بهذا التحديث:**
> - **نظام حسابات كامل (بدون باسورد)**: يحتاج تغييرات كبيرة بالبنية (تسجيل دخول، ترحيل الملكية من التوكن الحالي لحساب دائم)، ونظام التوكن الحالي بديل عملي عنه لحد الآن.
> - **إشعارات واتساب تلقائية**: تحتاج خدمة خارجية مدفوعة (مثل Twilio) لإرسال رسائل واتساب تلقائياً، وغير ممكنة بحل مجاني بالكامل. البديل الحالي (زر تواصل واتساب مباشر) يغطي نفس الحاجة تقريباً بدون تكلفة.

## التحديث الثاني — بحث وفلترة ومزايا إضافية
1. **بحث وفلترة**: خانة بحث فورية بالاسم/الوصف/المطلوب، بالإضافة لفلترة حسب الجامعة والتصنيف معاً.
2. **تصنيفات الأغراض**: كتب دراسية، قرطاسية، إلكترونيات، أثاث ومستلزمات سكن، ملابس، أخرى (قابلة للتعديل من `CATEGORIES` في `server.js`).
3. **مشاركة الإعلان**: زر "🔗 مشاركة" على كل بطاقة يفتح نافذة المشاركة الأصلية بالهاتف (أو رابط واتساب كبديل) مع رابط مباشر لصفحة الغرض `/item/:id`.
4. **عداد المشاهدات**: يزداد تلقائياً كل مرة يُفتح فيها رابط تفاصيل الغرض.
5. **إعلاناتي**: زر بالشريط العلوي يعرض فقط الإعلانات المنشورة من نفس الجهاز.
6. **الوقت النسبي**: "منذ يوم"، "منذ 3 أيام"... بدل التاريخ الكامل.
7. **صور متعددة**: حتى 4 صور لكل غرض، مع معرض صور بنقاط تنقل بصفحة التفاصيل.
8. **الوضع الليلي**: زر 🌙/☀️ بالشريط العلوي، يحفظ التفضيل بالمتصفح.
9. **حالات فارغة ذكية**: رسالة مختلفة حسب السياق (لا نتائج بحث / لا إعلانات لي / لا إعلانات إطلاقاً).
10. **صفحة تفاصيل مستقلة**: كل غرض له رابط خاص به `/item/:id` قابل للمشاركة والفتح المباشر.
11. **نافذة "عن المنصة"**: شرح مبسط لفكرة التطبيق، بالإضافة لنافذة دعم المطور الموجودة سابقاً.

## الميزات السابقة (التحديث الأول)
1. **اختيار الجامعة**: عند إضافة غرض، يختار الطالب جامعته من قائمة تضم أبرز جامعات الأردن (يمكن تعديل القائمة من `JORDAN_UNIVERSITIES` في `server.js`).
2. **حذف الإعلان**: يظهر زر "🗑️ حذف" فقط لصاحب الإعلان على نفس الجهاز/المتصفح الذي نشره (بدون حاجة لتسجيل دخول).
3. **تمت المقايضة**: يستطيع صاحب الإعلان تعليمه بأنه تم تبديله عبر زر "✅ تمت المقايضة"، فتظهر شارة حمراء على الصورة ويختفي زر واتساب، مع إمكانية التراجع عن الحالة.
4. **الحذف التلقائي بعد 30 يوماً**: يقوم السيرفر بفحص جميع الإعلانات عند كل طلب لعرضها، وأيضاً كل 12 ساعة تلقائياً، ويحذف أي إعلان مضى على نشره أكثر من 30 يوماً مع حذف صورته من `uploads/`.
5. **ادعم المطور**: زر ظاهر في الشريط العلوي وفي الفوتر، يفتح نافذة تعرض رقم محفظة أورانج موني (`962771587863`) مع إمكانية النسخ بضغطة واحدة.

> **كيف تعمل ميزة الحذف/تعديل الحالة بدون حسابات؟**
> عند نشر إعلان، يولّد السيرفر "توكن ملكية" سري خاص بذلك الإعلان، ويُحفظ تلقائياً في `localStorage` بمتصفح الجهاز الذي نشر منه المستخدم. أزرار "حذف" و"تمت المقايضة" تظهر فقط إذا كان الجهاز يملك هذا التوكن — لذلك لن تظهر لأي مستخدم آخر، ولن تظهر حتى لنفس الشخص إذا فتح الموقع من متصفح أو جهاز مختلف.

## ملاحظات مهمة
- كل الإعلانات تُحفظ في `data/items.json` وكل الصور تُحفظ في مجلد `uploads/` — لن تضيع البيانات عند إعادة تشغيل السيرفر أو إعادة تشغيل الهاتف.
- رقم الواتساب يجب إدخاله مع رمز الدولة وبدون "+" أو مسافات (مثال: `966512345678`)، والزر سيفتح محادثة واتساب مباشرة مع رسالة جاهزة.
- الحد الأقصى لحجم الصورة الواحدة هو 5 ميجابايت.
- لتغيير المنفذ (Port) الافتراضي (3000)، شغّل السيرفر هكذا:
  ```bash
  PORT=8080 npm start
  ```
